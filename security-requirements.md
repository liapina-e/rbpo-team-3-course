# Требования безопасности

| ID | Требование | Критерий приёмки | Связанные T / D (позднее) |
| --- | --- | --- | --- |
| SR-01 | Система выдаёт содержимое файла только его владельцу и получателю, у которого есть действующее разрешение на этот файл (срок не истёк, разрешение не отозвано). Знание идентификатора файла само по себе доступа не даёт. Нарушение раскрывает материал, который владелец передавал ограниченному кругу лиц на ограниченный срок, и вернуть его невозможно (`PROJECT.md`, раздел 5). ASVS: `v5.0.0-8.2.2`. | При запросе содержимого файла владельца A пользователем C без разрешения или запросом без аутентификации действие отклоняется, содержимое не передаётся. При запросе получателя B после наступления момента окончания срока или после отзыва разрешения действие отклоняется, содержимое не передаётся. Получатель B с действующим разрешением и владелец A получают содержимое файла. | — |
| SR-02 | Система допускает выдачу, отзыв и продление разрешений на файл только его владельцем. Нарушение даёт доступ лицу, которому владелец его не предоставлял, продлевает доступ сверх решения владельца или возвращает доступ после отзыва (`PROJECT.md`, раздел 5). | При попытке получателя B выдать разрешение на файл владельца A пользователю C или продлить собственное разрешение действие отклоняется, набор разрешений файла и их сроки остаются прежними. При попытке пользователя C отозвать разрешение получателя B на файл A действие отклоняется, разрешение B продолжает действовать. Владелец A может выдать разрешение пользователю C и отозвать его. | — |
| SR-03 | Система показывает перечень получателей файла и состояние их разрешений только владельцу файла, а метаданные файла — владельцу и получателю с действующим разрешением. Нарушение раскрывает, чем и с кем делится владелец, даже если содержимое остаётся недоступным (`PROJECT.md`, раздел 5). | При запросе перечня получателей файла владельца A получателем B или пользователем C действие отклоняется, сведения о получателях и их разрешениях не передаются. При запросе метаданных файла A пользователем C без разрешения действие отклоняется, имя и размер файла не передаются. Владелец A получает перечень получателей своего файла с состоянием их разрешений; получатель B с действующим разрешением получает метаданные файла. | — |
